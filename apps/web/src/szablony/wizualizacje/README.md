# Wizualizacje

Szablon: `/szablony/wizualizacje`, komponent `Wizualizacje.tsx`. Pusty prototyp: sam układ, bez logiki i danych.

## Co to jest

Format nauki: interaktywny model pojęcia (wykres z suwakami, algorytm krok po kroku, tekst z zaznaczaniem parafrazy).

## Po co

Część pojęć trzeba zobaczyć w ruchu, żeby je zrozumieć. Wizualizacja nie ocenia, tylko przygotowuje do ćwiczenia.

## Jak działa

1. Wybór modelu dla przedmiotu.
2. Obszar modelu przerysowywany na żywo.
3. Parametry (suwaki) i pytania Pestki do sprawdzenia suwakiem.
4. Obserwacje do potwierdzenia, potem szybka runda.

Numery odpowiadają pomarańczowym znacznikom na stronie szablonu.

## Od czego zależy

- Projekt: `docs/nauka-wizualizacje.html`.
- Warsztat informatyki (`warsztat/`) dla algorytmów.

## Do zrobienia

- [ ] Komponent wykresu funkcji (SVG, bez ciężkich bibliotek) z parametrami.
- [ ] Model „algorytm krok po kroku” (tablica, wskaźniki, krok w przód i w tył).
- [ ] Model tekstu z zaznaczaniem parafrazy dla języków.
- [ ] Katalog wizualizacji przypiętych do umiejętności.
- [ ] Pytania Pestki do modelu („co się stanie, gdy…”).
- [ ] Dostępność: opis tekstowy stanu modelu dla czytników ekranu.
